🔐 什么是 NodeCrypt？

NodeCrypt 是一个真正的零知识端到端加密聊天系统。采用无数据库架构，所有消息均在您的设备本地完成加密，服务器仅作为加密数据的盲中转站，无法获取任何明文内容。

🚀 快速开始

  1. 输入用户名： 选择在房间中显示的昵称，支持任意名称
  2. 设置房间名： 房间的唯一标识，相当于房间号
  3. 设置房间密码： 参与端到端密钥派生，提供额外的加密防护
  4. 点击进入房间： 系统自动进行 ECDH 密钥交换，开启加密对话
重要提示：相同房间名但不同密码是两个完全独立的加密空间，互不可见。

🔑 安全特性

  • 端到端加密： Curve25519 + ChaCha20 + AES-256 混合加密体系
  • 密码增强派生： 房间密码作为密钥派生因子，服务器盲区隔离
  • 零历史记录： 所有数据仅在内存中临时存在，新加入者无法回溯历史
  • 完全匿名通信： 无需注册账号，不收集任何个人隐私数据
  • 多平台部署： 支持 Cloudflare Workers、Docker 自建及本地部署

💡 使用技巧

  • 私聊功能：点击成员列表中的用户头像即可发起端到端加密私聊
  • 文件发送：支持批量文件拖拽、分卷自适应压缩与多图发送
  • 一键分享：右上角菜单可一键生成加密邀请链接
